sample-markdown

Render Markdown on Div exactly as Chromium renders it. This page mixes the common README elements.

Install

cargo add divui

Features

  • GitHub Flavored Markdown: tables, task lists, strikethrough
  • Light and dark themes from github-markdown-css
  • Headings and paragraphs
  • Syntax highlighting
PackageRole
react-markdownMarkdown to elements
github-markdown-cssGitHub's look

Note Div has no webview and no JavaScript.
