# sample-markdown

Render **Markdown** on [Div](https://github.com/build-with-div/div) exactly as
Chromium renders it. This page mixes the common README elements.

## Install

```sh
cargo add divui
```

## Features

- GitHub Flavored Markdown: tables, task lists, ~~strikethrough~~
- Light and dark themes from `github-markdown-css`
- [x] Headings and paragraphs
- [ ] Syntax highlighting

| Package | Role |
| --- | --- |
| `react-markdown` | Markdown to elements |
| `github-markdown-css` | GitHub's look |

> **Note**
> Div has no webview and no JavaScript.
